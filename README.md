# Dog Whistle Clicker — Support

Official responsive English and Spanish support website for Dog Whistle Clicker by Casaxmore.

- Website: https://casaxmore.github.io/dogwhistle-support/
- Contact: casaxmore@gmail.com
- GitHub Pages publishes the root of the master branch.
- English is the default; use `?lang=es` or `?lang=en` for a direct language link.
- `privacy.html` explains support website and correspondence privacy. The app has a separate privacy policy.
- No analytics, external fonts, advertising scripts or contact-form backend. Keep `app-ads.txt` unchanged.

Preview locally with `python3 -m http.server 8080`.
